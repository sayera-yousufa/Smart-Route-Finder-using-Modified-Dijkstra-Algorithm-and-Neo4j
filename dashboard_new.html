Project Overview

Smart Path Finder is an innovative navigation platform designed to simplify movement within complex university campuses and across cities. Our goal is to provide accessible, efficient, and personalized routing for all users, including students, visitors, and those with accessibility needs.

Key Features:

  • Campus Navigation: Optimal routes considering accessibility, crowd levels, and distance, with interactive maps.
  • Regional Navigation: Real-time city-wide routing using OpenStreetMap and Neo4j, with address autocomplete.
  • Unified Dashboard: Seamless access to both navigation systems through an intuitive interface.

Built with Flask, Neo4j, Leaflet.js, and OSMNx, Smart Path Finder enhances mobility and accessibility for diverse users.
